# 미드나이트 클럽 3 DUB 에디션 리믹스 한글화 용어집·규칙

## 출력 형식
- 파일: `ko_NN.tsv`, 한 줄에 `영문원문<TAB>한글번역`. 원문 칸은 src.tsv 의 원문을 **한 글자도 바꾸지 말고** 그대로 복사.
- 이스케이프: 줄바꿈 `\n`, 캐리지리턴 `\r`, 탭 `\t`, 역슬래시 `\\` (원문과 같은 방식).
- 번역하지 않을 줄(고유명사만 있는 줄, 노래 제목 등)은 생략해도 된다(원문 유지).
- `%s` `%d` 개수·순서 그대로 유지. `\n`/`\r\n` 줄바꿈은 원문과 비슷한 위치에 유지(줄 수가 늘지 않게).
- 버튼 기호 `⃞ 〇 ∆ ⊗ └ ┘ ╚ ╝`, `®`, 따옴표 등 특수문자는 그대로 둔다.
- 문장 끝 공백 등 앞뒤 공백도 원문과 맞춘다(목록 정렬용 공백 포함).
- 길이: 화면 폭이 좁다. 한글은 영문 대문자 1자 정도 폭이므로 메뉴 항목·버튼·제목은 짧게(원문 글자 수 이하 권장).
- 말투: 안내·설명문은 "~합니다/~하세요" 체. 메뉴·항목명은 명사형. 대결 상대 소개·도발은 자연스러운 구어 허용.
- 외부 번역기 사용 금지. 직접 번역.

## 유지(영문 그대로)
- 차량·바이크 제조사/모델명: Cadillac Escalade, Dodge Charger, Hotmatch Skully, Kawasaki Ninja ZX 12R 등
  (단 "Stock Exhaust" 같은 부품 설명은 번역: "1964 Chevy Impala Stock Exhaust" → "1964 Chevy Impala 순정 머플러")
- 부품 브랜드: Vince's, Apone Team Racing, A'pexi, West Coast Choppers 등
- 인명(레이서 이름): Dre, Roy, Vanessa, Angel ...  → 한글 표기(드레, 로이, 바네사, 엔젤...)로 옮긴다.
  단 이름 단독 줄은 영문 유지 가능(인명만 있는 줄은 원문 유지 권장).
- 음악: 곡명·"by 아티스트" 줄은 원문 유지. "Music: Atlanta" → "음악: 애틀랜타"
- DUB, DNAS, SCEA, PlayStation®2, memory card (PS2) → "메모리 카드(PS2)"
