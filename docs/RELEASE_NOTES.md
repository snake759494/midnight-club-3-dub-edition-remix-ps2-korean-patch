# 미드나이트 클럽 3: DUB 에디션 리믹스 PS2 북미판 한글 패치 v1.2

SLUS-21355 북미 원본용 정식 한글 패치입니다. 첨부 파일은 한글 패치 xdelta와 PCSX2 16:9 와이드 패치 pnach이며, 원본 ISO·게임 파일·폰트는 제공하지 않습니다.

- 메뉴·옵션, 커리어·도쿄 챌린지·아케이드, 레이스 설명·대결 상대 소개, 보상·해제 안내, 레이스 에디터, 메모리 카드·네트워크 안내 등 문자열 3,204개와 영상 자막 1,569큐 한글화(외부 기계 번역 미사용).
- 차고·상단 배너·하단 버튼 안내·대화상자·내비 시스템·로딩·보상 화면 등 플래시 UI 전부 한글 표시(플래시 글꼴 1,526개에 한글 추가).
- 차량·바이크 이름 한글 표기(64 임팔라, 닷지 차저 SRT8 등), 게임 그림 글자 51장과 고정 문구(가속/최고속도/핸들링, 뒤로, 도시명, 차종) 한글화.
- 인명, 곡명·아티스트, 브랜드·클럽 로고, 크레딧, 로딩 화면 오른쪽 위 LOADING은 원문 유지.
- PCSX2에서 부팅·법적 고지·타이틀·프로필·메뉴·로딩·차고(관리·구매·성능 숍)·도시 주행 HUD·일시정지·영상 자막·내비 시스템·와이드 패치 확인, 공개 소스 재빌드 및 xdelta 복원 해시 일치. 전체 플레이, 온라인, 레이스 에디터 세부 화면, 실기는 미검증입니다.

## 첨부 파일

- `Midnight_Club_3_DUB_Remix_PS2_KO_v1.2.xdelta`: 한글 패치(북미 원본 ISO용)
- `SLUS-21355_3021E351.pnach`: PCSX2 16:9 와이드 패치(한글판 CRC 3021E351용). 내장 와이드 패치 이식 + 직접 만든 HUD·메뉴 보정

## 한글 패치 적용

1. xdelta3(또는 xdeltaUI)를 준비합니다.
2. 원본 `Midnight Club 3 - DUB Edition Remix (USA).iso`의 SHA-256이 아래 값과 같은지 확인합니다.
3. 명령: `xdelta3 -d -s "Midnight Club 3 - DUB Edition Remix (USA).iso" Midnight_Club_3_DUB_Remix_PS2_KO_v1.2.xdelta "Midnight Club 3 - DUB Edition Remix (Korean).iso"`
   - xdeltaUI: Patch에 xdelta, Source File에 원본 ISO, Output File에 만들 ISO 이름을 넣고 Patch를 누릅니다.
4. 영상 자막은 기본값이 꺼짐입니다. 게임 안에서 옵션 → 게임 옵션 → **영상 자막 켬**으로 바꾸세요.

## 16:9 와이드 패치 사용법

한글 패치는 실행 파일을 수정해 게임 CRC가 원본 60A42FF5에서 **3021E351**로 바뀝니다. PCSX2 내장 와이드 패치는 CRC로 찾으므로 한글판에는 자동 적용되지 않아, 한글판 CRC용 파일을 첨부했습니다. 파일에는 두 항목이 있습니다.

| 항목 | 내용 |
|---|---|
| **Widescreen 16:9** | PCSX2 내장 와이드 패치를 그대로 옮긴 것. 3D 화면의 가로 시야를 16:9로 넓힙니다. |
| **Widescreen 16:9 HUD fix** | 직접 만든 보정. 주행 HUD(속도계·타코미터·미니맵·화살표·시간)와 메뉴·차고·로딩 화면이 가로로 늘어나지 않고 가운데 4:3 비율로 나옵니다. |

두 항목을 **함께** 켜세요(HUD fix만 켜면 화면은 4:3인데 HUD·메뉴만 좁아집니다).

**PCSX2 2.x(권장)**
1. 첨부한 `SLUS-21355_3021E351.pnach`를 `문서\PCSX2\patches\`(포터블은 `PCSX2 폴더\patches\`)에 넣습니다. 파일 이름은 바꾸지 마세요.
2. 게임 목록에서 Midnight Club 3 - DUB Edition Remix(한글 ISO)를 오른쪽 클릭 → 속성 → **패치** 탭 → **Widescreen 16:9**와 **Widescreen 16:9 HUD fix** 둘 다 체크.
3. 화면 비율은 패치가 자동으로 16:9로 바꿉니다. 수동 지정 시 속성 → 그래픽 → 디스플레이에서 화면 비율 **16:9**, FMV 화면 비율 전환 **4:3**(동영상은 원래 4:3).
4. 게임 시작 시 “2개의 게임 패치가 활성화되었습니다” 표시 확인. 목록이 비어 있으면 폴더 위치·파일 이름과 한글 ISO로 실행했는지 확인하세요.

설정 파일로 켜려면 `문서\PCSX2\gamesettings\SLUS-21355_3021E351.ini`에 다음을 저장합니다.

```ini
[Patches]
Enable = Widescreen 16:9
Enable = Widescreen 16:9 HUD fix

[EmuCore/GS]
AspectRatio = 16:9
FMVAspectRatioSwitch = 4:3
```

**PCSX2 1.6** — 파일 이름을 `3021E351.pnach`로 바꿔 `cheats_ws` 폴더에 넣고, 시스템 → 와이드스크린 패치 사용을 켠 뒤 비디오 → 창 설정에서 16:9를 고릅니다(1.6은 두 항목이 모두 적용되며 미검증).

일시정지 메뉴는 원래 오른쪽 정렬 디자인이라 오른쪽에 붙어 나옵니다. 끄려면 패치 탭 체크를 해제합니다. 원본(영문) ISO에는 PCSX2 내장 패치를 쓰고, 이 파일은 쓰지 마세요(HUD fix가 한글 패치 코드 영역을 씀). 자세한 내용은 저장소의 docs/WIDESCREEN.md를 보세요.
