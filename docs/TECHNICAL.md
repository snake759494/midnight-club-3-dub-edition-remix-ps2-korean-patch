# 기술 문서

## 한글 표시 방식
1. **문자열**: 문자열 표는 원래 UTF-16이고 일본어 등 다국어를 지원하므로, 영어(0번) 언어 칸에 한국어를 넣었다
   (모든 언어 칸 동일). 키는 Jenkins one-at-a-time 해시로 찾는 체인 해시표다.
2. **폰트(.fonttex + .tex)**: 글리프 표는 u16 코드·페이지·좌표이며, 0x100 이상 코드는 정렬 배열을 이진 탐색한다.
   smallspace(메뉴 본문)·arial12·chat·minidub(영상 자막)·bigstencil(영상 제목)에 실제로 쓰는 한글만 추가했다.
   페이지는 128×128(smallspace 256×256) 4bpp, 본 글자+그림자 두 장. 원본의 둥근 테크노 고딕에 맞춰
   **나눔스퀘어 네오 Bold**를 쓰고, 크기·기준선·자간은 원본 'H' 글리프와 헤더 자간값에서 자동 계산했다.
3. **ELF 패치(SLUS_213.55)**
   - 게임이 UTF-16 문자열을 UTF-8로 바꿨다가 그릴 때 바이트를 그대로 2바이트로 넓히는 루프(125곳)와
     2바이트 sprintf의 %s 처리를 UTF-8 복원 루틴 호출로 교체(한글이 3글자 쓰레기로 깨지던 문제 해결).
   - 플래시 UI로 가는 문자열 조회 111곳을 대체 조회로 돌려, 문자열 표에 추가한 `~키` 항목(영문 원문)을 쓰게 함.
   - 코드는 RAM 최상단(0x1FFC000, 16KB)에 두 번째 LOAD 세그먼트로 넣고 게임 메모리 관리자 상한만 16KB 낮췄다
     (BSS 끝/힙 시작을 옮기면 부팅이 깨짐).
4. **ASSETS.DAT("Dave" 아카이브)**: 파일 이름은 6비트 접두어 압축, 데이터는 raw deflate. 바뀐 파일은 끝에 추가하고
   목차·이름표를 다시 쓴다(새 항목은 정렬 위치에 삽입). DVD9의 빈 영역 안에서 ISO9660·UDF 크기를 갱신한다.

## 플래시 글꼴 구조와 처리(v1.1)
- pck = 0x80 머리 + 힙 이미지(포인터 0x06800000 기준). 로더는 객체 타입별로 포인터를 재배치한다.
- 글꼴 객체는 텍스처 글꼴: 코드 표(선형 탐색, UTF-8 디코드는 런타임 0x210bc0)·진행폭·글리프 레코드
  (아틀라스 x,y,w,h + 기준선 기준 사각형)·페이지 바이트 표·텍스처 목록(128×128 PSMT4, CLUT 알파 16단계).
- 한글 픽셀 페이지(20px, 20장)는 ELF가 RAM 최상단 0x1FD0000에 한 벌 올리고, 각 글꼴의 텍스처 목록 뒤에
  그 절대 주소를 붙인다(텍스처 수 필드는 원래 값이라 로더가 재배치하지 않음). pck에는 표만 추가된다.
- 플래시 pck는 원래처럼 비압축으로 저장해야 한다(압축하면 런타임이 멈춤).
- ASSETS.DAT는 원래 순서·정렬을 지키며 전체를 다시 쓰고, 바뀐 플래시 파일의 중복 사본은 하나로 합친다
  (DVD9 0번 레이어 여유가 약 18MB뿐이기 때문).


## 와이드 패치 구현
`SLUS-21355_3021E351.pnach` (한글 패치 ELF, CRC 3021E351 전용. 내장 패치는 원본 CRC 60A42FF5용이라 한글판에 적용되지 않는다)
- **Widescreen 16:9**: PCSX2 내장 와이드 패치를 옮긴 것. 화면비 상수(0x527e14, 4:3=1.3333)를 16:9=1.7778로 바꿔 가로 시야를 넓힌다.
- **Widescreen 16:9 HUD fix**(직접 제작): 주행 HUD가 가로로 늘어나지 않게 가운데 4:3 비율로 그린다.
  속도계·타코미터(바늘 포함)·미니맵·3D 화살표·백미러·시간/순위 글자가 원래 비율로 보인다. 메뉴·차고 등 플래시 UI와 3D 장면은 그대로.
  - 게임 2D 루틴은 화면 x(0..W, W=512)에 원점을 더해 GS 좌표를 만든다. 사각형(0x52afb8)과 글자(0x52b1f0)는
    호출자가 HUD 코드(0x270000~0x2a0000)일 때만 x' = W/8 + 0.75x 로 바꾼다(호출자 판정은 스택에 저장된 ra).
  - HUD 3D 뷰포트 설정(0x530f38) 호출 4곳(미니맵 2·백미러·화살표)은 x·폭을, 게이지 직교 투영(0x531420) 호출 3곳은 가로 범위를 4/3배로 넓힌다.
  - 코드는 한글 패치 코드 영역의 빈 곳(0x1fff000~)에 둔다. 생성: `python tools/hudfix.py`
- 설치: `문서\PCSX2\patches\`에 복사 → 게임 속성 → 패치에서 **Widescreen 16:9**와 **Widescreen 16:9 HUD fix**를 체크(화면비는 자동 16:9).
  - 메뉴·차고·로딩 화면(플래시 UI)도 보정: 플래시 x 배율(0x70f1b0)을 0.75배로 하고 정점 x를 [0, 폭×3/4]로 제한한 뒤 화면 폭/8을 더한다(4:3 무대 밖 도형이 왼쪽에 겹치는 것 방지)
    (훅 0x20b65c·0x20ef08·0x20f038·0x210238). 3D 배경은 16:9 전체 그대로.
- 일시정지 메뉴는 원래 오른쪽 정렬 디자인이며 이번 보정이 적용되지 않는다.
- 테스트 도구: `tools/vpad.py`(PINE + 테스트용 가상 패드 pnach 섹션, 배포 pnach에는 없음), `tools/devpatch.sh`.
